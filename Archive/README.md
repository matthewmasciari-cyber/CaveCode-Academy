# CaveCode Academy Archive

This folder contains historical development scaffolding moved out of the production project root.

## Folders

- `Installers/` — historical `apply-*` and `replace-*` pass scripts
- `Repairs/` — historical `repair-*`, `recover-*`, `fix-*`, and `enforce-*` scripts
- `Audits/` — historical `audit-*` scripts
- `Backups/` — pass-generated backup and audit folders
- `Reports/` — standalone audit reports and state snapshots

## Important

The production application remains in:

- `Pages/`
- `Components/`
- `Services/`
- `Layout/`
- `CourseEngine/`
- `wwwroot/`

Do not load archived backup files as production source code. The archive exists only for history and recovery.
