# C++ Engine Foundry — Pass 3

## Dependencies and commands

```bash
cd /workspaces/CaveCode-Academy
python3 apply-cavecode-shared-course-engine-pass-1.py
python3 apply-cavecode-cpp-course-shell-pass-2.py
python3 apply-cavecode-cpp-chapter-1-pass-3.py
dotnet build
dotnet run
```

Hard-refresh with `Ctrl + Shift + R`, then open `/cpp`.

## Playable Chapter 1 modules

1. Boot the Engine Foundry
2. Send a Foundry Status Message
3. Store the Engine Temperature
4. Choose the Right Engine Data Types
5. Label the Foundry Systems
6. Read an Operator Command
7. Calculate Engine Output
8. Build the First Foundry Dashboard

Each module has Learn, Guided, Fill, Predict, Debug, Recall, Transfer, and
Complete stages.

## Progression and rewards

- Validated lines are counted as C++ lines.
- C++ XP is tracked independently from C# and Python.
- Modules use the same XP schedule as the current courses.
- Module 8 awards the normal chapter-completion XP bonus.
- Chapter 1 unlocks the `Forge Core Ignited` achievement.
- Its claimable reward is the `Foundry Apprentice` title and 100 crystals.
- Progress uses `cavecode.cpp.progress.v1`.
- Modules 9–40 remain visible and locked.

The browser validates expected C++ structure. It does not falsely claim to
compile arbitrary C++ code.
